## 维护说明

### 何时更新
- 每次故障处置完毕后，运行更新脚本将经验入库

### 日常查询
- 双击 `查询操作手册.bat`
- 输入系统名后，可查看对应系统的故障模式、常用排查命令，并自动打开对应手册

### 如何更新

**方式一：按序号更新**
```bash
python scripts/kb_updater.py --seq 74
```

**方式二：更新最新故障**
```bash
python scripts/kb_updater.py --latest
```

### 月度维护流程
1. 每月更新 Excel 故障记录表（追加本月故障）
2. 运行 `python scripts/monthly_analyzer.py` 生成本月分析报告
3. 对新出现的高频故障，运行 `kb_updater.py` 更新指引
4. 人工审核新增/更新的指引内容
