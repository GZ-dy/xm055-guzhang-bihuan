# 【XM055】故障闭环系统

将已经处理过的报障整理为统一事实记录，再生成报告、台账、手册匹配和通知材料。

## 系统功能

- 校验故障事实，信息不足时提示缺失字段。
- 生成 Word 报告、Excel 台账、手册匹配和邮件预览。
- 提供本地 CLI 与企业微信机器人入口。
- 记录重复检查、发送状态与恢复处理。

## 怎么使用

1. 普通试用优先从 Releases 下载 v0.2.0 Windows 便携包和对应 SHA-256 文件。
2. 校验后完整解压到新目录，使用 START_LOCAL_DEMO.cmd 查看本地演示。
3. 维护源码的统一入口为 run_closed_loop.py；详细参数见原版说明。
4. 正式接入企微、在线表或 SMTP 前按 docs/HANDOVER_OPERATIONS.md 配置和验收。
5. 本次没有启用真实发送或补发历史任务。
